재생을 누르고 룩 두 개를 바꿔보세요. 빛이 음악을 더 느끼게 해주는지, 아니면 선을 읽는 데 방해가 되는지만 보시면 됩니다. 밀리초 측정은 필요 없습니다.

LOOK 01

Luminous silk

비올라가 주인공인 차분한 장면. 얇은 빛, 따뜻한 금색, 절제된 잔상.

LOOK 02

Neon impact

공격 순간을 크게 느끼는 장면. 강한 글로우, 입자, 장식의 반동과 배경 흔들림.

효과를 어디에 쓰는가

개념이 작업실에서의 역할
훅 / 스크롤 스토퍼첫 약 2초의 타이틀 대비 변화. 첫 소리의 빛과 함께 시선을 잡습니다.
비트 싱크 / 오디오 리액티브실제 원음의 음량·공격 변화로 장식 밝기와 크기를 움직입니다. 추출한 어택 후보이며 검증된 강박 그리드는 아닙니다.
킥 / 히트 / 펄스검출 어택에서 빛의 링과 배경 후광이 확장 후 감쇠합니다. 음높이 선이나 전체 화면을 펌프하지 않습니다.
글로우 / 블룸빛 가닥 주변의 부드러운 번짐. 물리 기반 HDR 블룸이 아닌 2D 근사입니다.
이징 / 오버슈트 / 바운스타이틀의 부드러운 전환과 장식 링의 해석적 감쇠 반동. 리본 중심선의 시간·pitch를 지연시키지 않습니다.
트레일 / 잔상음표 진입 후 짧은 빛의 꼬리. 실제 셔터 모션 블러가 아닌 장식 잔상입니다.
파티클악보의 음표 진입에서 작은 입자가 흩어집니다. 실제 악기별 어택 검출이나 특정 논문 재현으로 주장하지 않습니다.
그라디언트 / 네온리본의 색과 하이라이트를 이어줍니다. 두 룩 모두 악기 색을 유지합니다.
비네트 / 그레인 / RGB 어긋남장면 주변과 보조 빛의 질감. 각각 강도를 조절할 수 있습니다.
9:16 / 세이프 존1080×1920 세로 구도와 상단·하단·우측 여백 가이드. 플랫폼 UI는 바뀔 수 있으므로 업로드 규격 보증은 아닙니다.
카메라 셰이크배경 장식만 짧게 움직입니다. 악기 선·재생선·제목은 안정적으로 유지합니다.
DOF / 심도다른 악기의 보조 광택을 흐리게 하고 중심 선은 유지합니다. 3D 물리 심도가 아닌 2D 초점 연출입니다.

음악과 시간

멘델스존은 사용자가 선택한 그림 앞당김 0.16초를 유지합니다. 베토벤은 기존에 확보한 동일 20초 오케스트라 발췌만 사용하며 제공 정렬을 유지합니다. 멘델스존에서 고른 보정값을 베토벤에 자동 적용하지 않습니다.

원음 리액션은 실제 오디오 시각을 따르고, 악보의 발음 표시·입자는 선택한 그림 시각을 따릅니다. 원음 전체의 크기를 특정 파트의 실제 dynamics로 해석하지 않습니다. 베토벤의 유명한 도입 동기는 현재 발췌에서 재검증한 것으로 표시하지 않습니다.

저장과 출력

룩 설정은 JSON으로, 현재 프레임은 PNG로 저장합니다. ‘영상 녹화’는 원음과 Canvas를 브라우저에서 실시간 기록합니다. 프레임 누락이 가능한 개발용 프리뷰이며 최종 프레임 정밀 MP4 마스터와 구분합니다. 세이프 존은 저장 영상과 PNG에 포함되지 않습니다.

현재 설정의 재불러오기는 다음 개발 범위입니다. JSON에는 입력 run·표시 시각·연출 값이 남으므로 재현의 기준으로 사용할 수 있습니다.
