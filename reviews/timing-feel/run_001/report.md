# B4.4 소리와 리본의 체감 타이밍

사용자 의견: 따라보기 쉽지만 소리보다 그림이 조금 늦게 느껴진다. 생생함·그래픽 효과는 이후 검토한다.
같은 원음으로 기존·0.08초 앞당김·0.16초 앞당김을 전환하는 비교 화면을 추가했다.
사용자에게 밀리초 측정이나 음표별 검수를 요청하지 않는다. 기존이 기본값이다.
리본 전체 시각을 audio.currentTime + lead로 정하는 표시 전용 후보다. 원본 데이터·원음은 그대로다.
발음 강조와 가로 이동은 같은 표시 시각을 사용한다. 구간 양끝은 [0,22]로 제한한다.
장치 지연 측정·확정 정렬 보정·그래픽 효과·spring 구현이 아니다.
기존 SVG 660프레임 해시·후보별 이동된 발음 경계 ±0.1us·실제 entry 조작 stub을 검사했다.
실제 브라우저 재생·사람의 청취 판정은 미수행이며 사용자 후보 선택은 대기다.
