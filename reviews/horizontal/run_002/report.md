# B4.3 가로 흐름 A/B

사용자의 “지금까진 다 맞는거같은데” 확인 후 B4.3을 구현했다. 수동 정확도 검수는 보류 상태다.
A는 125px/연주초, B는 악보 beat를 같은 간격으로 배치한다. B의 px/beat는 전체 대응 구간의 가로 길이를 A와 맞췄다.
모든 발음 판정은 원래 performance 이벤트와 같은 audio time을 읽는다. inverse mapping을 발음 판정에 쓰지 않는다.
B에서 가로 좌표만 단조 clock으로 변환한다. 시작/끝·playhead 교차·pitch·성부·중음·쉼은 유지한다.
대응 범위 밖의 앞뒤 문맥은 endpoint-average 기울기로 표시하되 note alignment를 새로 추정하지 않는다.
B의 곡선 전환 폭은 가로 좌표에 맞춘 시각 보간이며 발음 이벤트를 바꾸지 않는다.
원시 DTW의 속도 계단이 B 이동에 남을 수 있다. 물리효과·정렬 보정 또는 검증된 루바토가 아니다.
기존 A 660개 SVG는 새 opt-in clock 추가 후에도 바이트 일치한다. 동일 발음·pitch·발음점 좌표를
900개 시점(정확한 경계와 양쪽 포함)에서 검사했고 endpoint playhead 오차 최대는
0px다. 기본 표현은 A를 유지한다.
22초 B MP4를 기존 공유 SVG/native Agg 경로로 생성하고 PTS·음원 mux·대표 픽셀을 검사했다.
A 영상은 새로 렌더하지 않고 승인된 원본을 그대로 복사했다. 입력·기존 파일 771개 해시를 보존했다.
A/B PNG는 실제 공유 SVG의 native raster이며 브라우저 캡처가 아니다. 브라우저 실제 재생·새 청취 승인은 대기다.
