# B3.2 beat→원본 연주 초 매핑

B3.1 run_002의 악보·DTW 후보·실제 원음을 재사용했다. 악보 JSON과 원음은 바이트 일치한다.
별도 beat-alignment/0.1.0 JSON으로 원본/발췌 beat·악보 초·연주 초를 보존한다.
템포 변화점이 후보의 두 anchor 사이에 있으면 knot를 추가하여 기존 초 기반 보간을 정확히 유지한다.
단조성과 유효 범위를 검사하며 범위 밖 요청을 거절한다. 기존 끝점 추정 가정은 승계한다.
1072개 조밀한 beat와 음표 경계에서 기존 매핑 차이 최대 7.11e-15초,
역변환 차이 최대 7.11e-15 beat를 확인했다.
직선은 후보 양 끝을 beat 축으로 이은 비교 기준이며 정답이 아니다. 편차를 정렬 오차나 루바토로 해석하지 않는다.
청취 화면은 외부 fetch 없이 열린다. 모드 변경은 현재 오디오 위치를 유지하며 beat 표시만 바꾼다.
beat 조절·마디 버튼은 선택 모드의 시각으로 seek한다. 기존 리본·음색·물리효과는 변경하지 않는다.
입력·기존 결과 520개 파일 해시를 보존했다. 사람의 청취와 정확도 검수는 대기다.
