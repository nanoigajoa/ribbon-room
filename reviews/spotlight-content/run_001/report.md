# B6.1 비올라 시각 강조

사용자가 B4.4의 더 앞당김을 선택했다. 표시 시각은 원음 +0.16초이며 관성 보정이 아니다.
그래픽·탄성 효과 보류를 유지하고 전체/비올라 강조 보기와 원음 포함 영상 두 개를 생성했다.
강조는 다른 파트 opacity를 0.45로 낮추는 기존 표현을 재사용한다. 음표·발음·pitch·나머지 파트 관계를 유지한다.
양쪽 모두 같은 표시 시계와 원음을 쓴다. 음원 강조·분리는 없다. 선택 전환 때 음악은 끊기지 않는다.
검토 질문은 노란 비올라를 덜 놓치고 따라갈 수 있는가다. 사용자의 정밀 측정을 요구하지 않는다.
동일 SVG에서 opacity를 제외한 전 요소 일치, 발음 경계·원음 mux·PTS·대표 디코딩 픽셀을 검사했다.
그림은 공유 SVG의 native Agg이며 브라우저 캡처가 아니다. 실제 청취 판정·정렬 정확도 검증은 별도다.
