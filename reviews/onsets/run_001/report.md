# B3.4 실제 진입 수동 검토·오차 보고

악보 기준 고정 beat 목표에서 11곳을 선택했다. 정렬 원점에 이미 쓰인 첫 진입은 보정용이다.
나머지 10곳은 평가용으로 고정하며 보정에 사용하지 않는다. source_note_id·part·pitch를 보존한다.
원음·악보·정렬은 B3.3 run_001과 바이트 일치한다. 확대 파형은 후보 중심이며 완전한 블라인드 검수는 아니다.
원음 범위 전체의 독립 수동 구간 입력, 후보 숨김, 확인·불확실·제외 및 이유, 저장·JSON 내보내기를 제공한다.
오차는 prediction - [manual upper, manual lower]이다. 불확실성 범위를 유지하고 midpoint는 부가 지표다.
원점 보정용과 불확실/제외 지점은 확인된 평가용 오차 집계에서 분리한다. 목표는 30fps 두 프레임(약 66.67ms)이다.
현재 확인된 평가용 0/10곳, midpoint MAE None.
수동 기록이 없으면 모든 오차는 null이다. 자동 파형·DTW 시각을 사람의 확인값으로 대체하지 않았다.
--annotations로 내보낸 JSON을 읽으면 별도 새 run에 오차표·수동 범위를 포함한 확대 그림을 만든다.
입력·기존 파일 554개 해시를 보존했다. 브라우저 청취와 실제 수동 시각 확인은 대기다.
