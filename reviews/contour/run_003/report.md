# B2.2 — 선율 리본 A/B

입력: 승인된 B2.1 run_003의 동일 15초 JSON·합성 기준음·설정. 출처는 provenance.json.
A: 승인된 기존 리본. B: 최고음 윤곽을 유지하며 동일 높이의 연속 구간을 병합하고,
최대 ±120ms / 양쪽 구간의 40% 이내 cubic 보간과 고정 폭의 옅은 띠를 적용한다.
음표 시작·끝·pitch·중음의 모든 가닥·밝은 발음 표시·고정 playhead는 변경하지 않는다.
쉼마다 별도 path이며 중음 최고음 선택은 윤곽에만 적용한다. 반복 발음은 원래 이벤트로 유지한다.
보간은 물리 시뮬레이션·실제 dynamics가 아니다. 곡선은 양 끝 음높이 범위 안에 있다.
기존 라이브러리와 Remotion 기본값은 승인된 baseline을 유지한다. 새 표현은 A/B 화면에서 검토한다.

검증: 기존 대표 SVG 6개 바이트 일치. 638개 시점에서 A/B의 모든 음표·발음·재생선 좌표 일치.
5개 연속 발음 run, 137개 곡선의 각 101개 지점에서
시간 단조성과 음높이 overshoot 없음을 검사했다. 짧은 음·중음·쉼·동음 병합 fixture 통과.
기존 미디어 제어 stub 검사 통과. 기존 381개 입력·출력 해시 유지.
PNG는 공유 SVG의 곡선·가닥·점 좌표 진단이며 옅은 띠도 포함하며 전체 타이포는 생략했다.
전체 표현은 SVG 및 재생 화면에서 확인한다. 브라우저 자동 조작·청취는 수행하지 않았다.
사용자 시각 검토 대기. 다음 단계는 B2.3 Viola 대비·가독성 검토다.
