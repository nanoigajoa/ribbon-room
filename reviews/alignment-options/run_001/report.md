# B3.5 수동 측정 없이 정렬 후보 비교

사용자 요청으로 B3.4 수동 진입 측정을 보류했다. 기존 DTW A와 4 quarter beat 간격 재표본 B,
같은 끝점 직선 C를 같은 실제 녹음 22초·같은 리본 표현으로 비교한다. A/B/C는 별도 원음이 아니다.
새 정렬 엔진이나 합성 기준음을 만들지 않는다. 단순화는 독립 정확도 평가가 아니며 음표 시각을 바꾼다.
모든 194개 원본 음표의 onset·offset 변화와 ID·pitch를 기록했다.
기존 악보·정렬·음원·평가 지점을 보존하며 B3.4 라벨을 읽거나 보정에 쓰지 않았다.
같은 원음 시계에서 각 후보의 역함수로 악보 시각을 읽는다. 성부 강조는 시각에만 적용한다.
음원 위치·재생 상태·속도는 비교 선택에 따라 바뀌지 않는다. 새 물리효과는 없다.
수동 정답이 없어 승자를 확정하지 않는다. 기존 raw 후보 A를 후속 실험의 임시 기준으로 유지한다.
대안의 매끄러움과 정확도를 구별하며, note shift를 실제 alignment error라고 표시하지 않는다.
공유 SVG 2463개 시점에서 후보별 발음을 원본 음표 endpoint 매핑과 비교했다.
기존 파일 571개 SHA256을 보존했다. PNG는 SVG 좌표 진단이며 브라우저 캡처가 아니다.
브라우저 재생·청취와 정렬 품질 승인은 대기다. 사용자 수동 측정을 이번 구현 진행 조건으로 요구하지 않는다.
