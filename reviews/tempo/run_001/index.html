B3.3 · 템포·루바토 진단 · 검토 대기

박 사이의 속도 변화, 어느 범위로 볼까?

멘델스존 Op.80 I악장 · Musopen String Quartet 실제 원음. 기존 DTW 후보에서 계산한 템포를 1·2·4박 범위로 비교합니다. 정렬 오차와 실제 루바토를 아직 구분하여 검증하지 않았습니다.

평균 범위를 바꿔도 현재 재생 위치와 음표 대응은 바뀌지 않습니다. 밝은 선은 선택한 박 범위의 평균이며 회색 선은 짧은 DTW 구간의 기울기입니다.

추정 범위와 단위

quarter BPM = 60 × 구간의 quarter beats ÷ 실제 연주 초 길이. 원시 BPM의 산술평균을 사용하지 않습니다. 중심점을 0.25박마다 계산하고, 양 끝에서 전체 창이 확보되지 않으면 값을 생략합니다. 전 구간 양 끝의 평균은 168.52 quarter BPM입니다.

1·2·4박 평균은 진단용입니다. 넓은 창은 짧은 변화를 완화하므로 실제 루바토의 정답으로 사용할 수 없습니다. 원시 경로의 기울기 변화에는 feature frame과 DTW 이동 규칙이 섞여 있습니다. 기존 끝점 추정의 불확실성도 이어집니다.

이 곡선은 리본·재생 시계·음표 진입을 수정하지 않습니다. 독립 공격음 확인과 타이밍 오차 측정은 다음 B3.4에서 진행합니다.
