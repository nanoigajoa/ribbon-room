# B3.3 템포·루바토 진단

기존 B3.2 run_001의 beat 정렬·악보·원음 22초를 바이트 일치로 보존했다.
원시 구간 526개의 quarter BPM을 60/(dt/dbeat)로 계산하고,
1·2·4 quarter beat의 완전한 중심 구간에서 초/박 평균을 역변환한 BPM을 비교한다.
유효 범위는 각 창의 반폭만큼 양 끝에서 제외하며, 0.25박 간격으로 표본화한다.
전 구간 끝점 평균은 168.521850 quarter BPM이다. 원시 DTW 기울기는 정량화된 이동 규칙의 영향을 받는다.
진단은 실제 루바토 검증이나 정렬 보정이 아니다. 같은 박에서 다른 창을 선택해도 원음 위치는 보존한다.
raw 경로·note onset·재생 시계·리본에는 평균값을 적용하지 않았다. 끝점 추정의 기존 한계도 유지한다.
기존 파일 534개의 해시를 보존했다. 독립 공격음 검수는 다음 B3.4 범위다.
